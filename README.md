# IntelSense AI

This repository contains a multi-service application for IntelSense AI.

- `frontend/`: React + Vite user interface
- `backend/`: Spring Boot API gateway with MySQL persistence
- `ai-service/`: FastAPI AI prediction and analysis microservice

## Run Locally
See `LOCAL_RUN_GUIDE.md` for the recommended local startup workflow.
From the repo root, you can also run `bash run-all.sh` to start services automatically.
